# Quickstart: 首页即知识分享（多书阅读器）验证指南

Feature: 002-knowledge-home | Date: 2026-11-04

前置条件：完成实现并执行 `cd site-src && npm run build && cp -R dist/. ..`；
在仓库根目录起本地服务：

```bash
python3 -m http.server 4000
```

## 场景 1：首页阅读器（US1）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1.1 | 打开 `http://localhost:4000/` | 左侧目录 + 右侧默认章节（README.md）渲染完成 |
| 1.2 | 点击目录中「01 架构总览」等条目 | 右侧渲染对应章节；hash 变为 `#/claude-code-book/<章节>.md` |
| 1.3 | 刷新页面 | 仍停留在当前章节 |
| 1.4 | 点击章节右上「查看源文件」 | 新窗口打开该章节原始 `.md` |
| 1.5 | 章节内含图片的页面 | 图片正常显示（基于 `/book/claude-code-book/` 解析） |

## 场景 2：多书（US2）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 2.1 | 首页可见书架/书籍切换（当前 1 本即显示单书标识） | claude-code-book 展示标题与简介 |
| 2.2 | 向 `book/books.json` 追加一本测试书（目录 `book/test-book/` 放 `SUMMARY.md` + 2 个 md），刷新首页 | 书架出现测试书，无需改任何代码 |
| 2.3 | 切换到测试书再切回 | 目录与内容正确切换，互不串扰 |
| 2.4 | 删除测试书目录但保留 books.json 登记，刷新 | 控制台警告，书架不渲染死链接 |

## 场景 3：旧入口兼容（US3）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 3.1 | 访问 `http://localhost:4000/book/` | 跳转到首页阅读器，选中 claude-code-book |
| 3.2 | 访问 `http://localhost:4000/book/claude-code-book/01-architecture-overview.md` | 浏览器直接显示原始 markdown 文件 |
| 3.3 | 访问 `http://localhost:4000/book/claude-code-book/`（保留的旧 Docsify 壳） | 旧阅读界面仍可用 |

## 场景 4：博客回归（FR-009）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 4.1 | 点击导航「文章」 | `/posts/` 列表正常 |
| 4.2 | 打开任一文章、归档、搜索 | 功能正常，无回归 |

## 场景 5：移动端（FR-008）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 5.1 | 窄屏（≤768px）打开首页 | 目录折叠为抽屉 |
| 5.2 | 抽屉中点击章节 | 内容切换且抽屉自动收起 |

## 失败排查

- 目录空白 → 检查 `book/<id>/SUMMARY.md` 是否存在、链接是否为相对 `.md`
- 内容区白屏 → 打开控制台看 fetch 路径；确认章节文件存在
- 书籍未出现 → `books.json` 语法错误或 id 与目录名不一致
